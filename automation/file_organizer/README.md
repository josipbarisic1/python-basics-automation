File Organizer

Organizes files into subfolders by type.

Run:

python file_organizer.py

What it does:
- Scans directory
- Detects file types
- Moves files to categorized folders
- Creates folders if needed

Input:
Place files in test_files/

Output folders:
- test_files/text/
- test_files/images/
- test_files/csv/
