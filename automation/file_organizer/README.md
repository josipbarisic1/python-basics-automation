File Organizer

Scans a folder and organizes files into subfolders by type.

How to run:
python file_organizer/file_organizer.py

What it does:
- Scans a directory for files
- Detects file types (text, images, CSV)
- Moves files into categorized folders
- Creates folders automatically if needed

Input:
Place files in test_files/

Example output:
- test_files/text/
- test_files/images/
- test_files/csv/
